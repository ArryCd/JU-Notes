Statistical Toolkit — Essential Framework

Prerequisite Mathematics  ·  Reif Ch. 1–2
Why Statistics?
A macroscopic system has ~1023 degrees of freedom. We cannot solve 1023 equations of motion. Instead, we make probabilistic statements: rather than asking what is the state, we ask how probable is each state? The entire edifice of statistical mechanics rests on one postulate: in equilibrium, all accessible microstates of an isolated system are equally probable (the postulate of equal a priori probabilities).

Gaussian Integrals — The Workhorse

Almost every partition function calculation reduces to Gaussian integrals. The master formula is:

∫−∞∞ e−αx² dx = √(π/α)    (α > 0) Gaussian integral — fundamental result

From this, by differentiation with respect to α, we get moments:

∫−∞∞ x² e−αx² dx = (1/2)√(π/α³) = √π / (2α3/2)
Trick: Differentiating under the integral sign
To evaluate ∫x2n e−αx²dx, differentiate the master Gaussian n times with respect to α and multiply by (−1)n. This is a powerful technique used repeatedly in calculating ⟨E⟩, ⟨E²⟩, etc.

The Gamma Function

For momentum integrals in spherical coordinates (e.g., relativistic gas), the Gamma function appears:

Γ(n) = ∫0∞ un−1 e−u du   ,   Γ(n+1) = n!   ,   Γ(1/2) = √π

Key values: Γ(1)=1, Γ(2)=1, Γ(3)=2, Γ(4)=6. For the ultra-relativistic gas, Γ(3) = 2! = 2 is used directly.

Stirling's Approximation

When computing the partition function for N indistinguishable particles, ln(N!) appears. For large N:

ln N! ≈ N ln N − N    (Stirling's approximation, N ≫ 1)
When to use it
Stirling's approximation is only valid for N ≫ 1 (thermodynamic limit). It is used to simplify ln ZN when the partition function involves N! from indistinguishability. Without it, expressions like ln(V/Nλ³) + 1 (the Sackur-Tetrode equation) cannot be derived cleanly.

Three Ensembles at a Glance

β and the Boltzmann Factor

β = 1/(kBT)     [units: J−1 or eV−1]

The Boltzmann factor e−βE is the relative probability of a microstate with energy E when the system is in contact with a heat bath at temperature T. At high T (small β), all states are nearly equally probable. At low T (large β), only low-energy states are occupied.

Thermodynamic Properties of N Distinguishable Classical Harmonic Oscillators in 2D

Canonical Ensemble  ·  Reif Ch. 7 · Pathria Ch. 3

The System

Consider N classical, distinguishable harmonic oscillators in 2 dimensions. Each oscillator can move in the x and y directions, giving 2 position and 2 momentum coordinates. The Hamiltonian for a single oscillator is:

H = px²/(2m) + py²/(2m) + ½mω²(x² + y²) Eq. (i) — Single oscillator Hamiltonian (2D)
Why "Distinguishable"?
In the canonical ensemble, if the particles are distinguishable (e.g., they are localized at lattice sites and we can label them), the total partition function is simply ZN = (Z1)N — no factor of 1/N! is needed. For indistinguishable particles (like an ideal gas), we must divide by N! to avoid Gibbs paradox.

Roadmap to Thermodynamic Properties

To get thermodynamic properties, SR Sir's notes outline four steps:

Compute the single-particle partition function Z1(T,V,N) from the phase-space integral.
Get the total partition function ZN = (Z1)N (since particles are distinguishable).
Compute the Helmholtz free energy: F = −kBT ln ZN.
Derive entropy S = −(∂F/∂T)V, internal energy U, pressure P, heat capacity CV, and chemical potential μ.

i) Single-Particle Partition Function

In classical statistical mechanics, the single-particle partition function integrates over phase space, weighted by the Boltzmann factor:

Z1 = (1/h²) ∫∫∫∫ e−βH dx dy dpx dpy

Here h² is the phase-space cell volume for 2D (one factor of h per degree of freedom). Substituting the Hamiltonian:

Z1 = (1/h²) [∫ e−β px²/2m dpx] [∫ e−β py²/2m dpy] [∫ e−βmω²x²/2 dx] [∫ e−βmω²y²/2 dy]
▶ Full derivation: Evaluating the Gaussian integrals

Each integral is Gaussian. For the momentum integral in x:

∫−∞∞ e−β px²/2m dpx = √(π / (β/2m)) = √(2πm/β)

Similarly for py. For the position integral in x (with α = βmω²/2):

∫−∞∞ e−βmω²x²/2 dx = √(π / (βmω²/2)) = √(2π/βmω²)

Similarly for y. Therefore:

Z1 = (1/h²) × (2πm/β) × (2π/βmω²) = (1/h²) × (4π²/β²ω²) = 4π²/(h²β²ω²)

Recognising β = 1/kBT and ħ = h/2π:

Z1 = (kBT/ħω)² = (kBT)²/(ħω)²

This can also be written as Z1 = (kBT/ħω)² since 4π²/h² = 1/ħ².

Z1(T,V,N) = (kBT / ħω)² Single-particle partition function — 2D harmonic oscillator

ii) Total Partition Function

Since the oscillators are distinguishable, the total partition function is just the product of N single-particle functions:

ZN = (Z1)N = (kBT / ħω)2N Total partition function — N distinguishable 2D oscillators

iii) Helmholtz Free Energy

F = −kBT ln ZN = −kBT · 2N · ln(kBT/ħω)
∴ F = −2N kBT ln(kBT / ħω) Helmholtz free energy

iv) Entropy

S = −(∂F/∂T)V = −∂/∂T [−2NkBT ln(kBT/ħω)]
= 2NkB ln(kBT/ħω) + 2NkBT · (1/T)
∴ S(E,V,N) = 2NkB [1 + ln(kBT/ħω)] Entropy — 2D classical harmonic oscillators

v) Internal Energy, CV, and Chemical Potential

From U = F + TS, or equivalently U = −∂(ln ZN)/∂β:

ln ZN = 2N ln(kBT/ħω) = −2N ln(βħω)
U = −∂(ln ZN)/∂β = −∂/∂β [−2N ln(βħω)] = 2N/β
∴ U = 2NkBT Internal energy — 2N quadratic degrees of freedom, each ½kBT
Equipartition Theorem
Each quadratic term in the Hamiltonian contributes ½kBT to the average energy. For N 2D oscillators: 4N quadratic terms (px², py², x², y² for each oscillator) × ½kBT = 2NkBT. This is the classical equipartition theorem, which holds exactly in the classical regime (high T).
CV = (∂U/∂T)N,V = 2NkB
P = −(∂F/∂V)T = 0    [H is volume-independent for oscillators]
⟨E⟩ per oscillator = U/N = 2kBT
Chemical Potential
μ = (∂F/∂N)T,V = ∂/∂N [−2NkBT ln(kBT/ħω)] = −2kBT ln(kBT/ħω) = −2kBT ln(kBT/ħω)

This is negative (assuming kBT > ħω, i.e., classical regime), which makes sense: adding one more oscillator to the system lowers the free energy in the high-T classical limit.

Conceptual Questions

Why does the partition function for a 2D oscillator depend on T² and not T?
The 2D oscillator has four quadratic degrees of freedom (two kinetic, two potential). Each Gaussian integral over a quadratic variable contributes a factor of √(π/α) ∝ β−1/2 ∝ T1/2. Four such integrals give a total T4/2 = T² dependence, with the 1/h² prefactor providing the correct dimensionless combination. In d dimensions, Z1 ∝ (kBT/ħω)d.
Why is pressure zero for a harmonic oscillator system?
The Hamiltonian H = p²/2m + ½mω²r² contains no explicit dependence on the volume V. The oscillator is "trapped" at a fixed centre — the restoring force is from the potential, not from container walls. Therefore ∂H/∂V = 0, and consequently P = −(∂F/∂V)T = 0. This contrasts with an ideal gas where the kinetic energy term gives rise to pressure.
What does "classical limit" mean here, and when does it break down?
The classical treatment is valid when the thermal energy kBT ≫ ħω — the level spacing of the quantum harmonic oscillator. In this limit, the discrete sum over quantum states Σ e−βnħω can be approximated by the continuous phase-space integral. At low temperatures (kBT ≪ ħω), only the ground state is occupied, and the classical result fails catastrophically. The quantum heat capacity approaches zero as T→0 (third law), while the classical CV = 2NkB is temperature-independent — the Einstein model captures this correction.

N Distinguishable Classical Harmonic Oscillators in 3D (Canonical Ensemble)

Canonical Ensemble · Einstein Solid framework  ·  Kittel & Kroemer Ch. 3

Hamiltonian

H = Σi=1N [pi²/(2m) + ½mω²xi²] 1D oscillators; each particle has one spatial degree of freedom

Note: in SR Sir's notes, this is written as a 1D oscillator Hamiltonian summed over N particles. For a 3D isotropic oscillator, just replace each 1D integral with a 3D one. The derivation is completely analogous.

Partition Function for One Oscillator

The single-particle partition function separates into a momentum integral (M.I.) and position integral (P.I.):

Z1 = (1/h) ∫−∞∞ e−βp²/2m dp · ∫−∞∞ e−βmω²x²/2 dx
▶ Derivation: Momentum and position integrals for 1D oscillator

Momentum integral (M.I.): Let α = β/(2m):

∫−∞∞ e−βp²/2m dp = √(π/α) = √(2πm/β) = √(2πmkBT)

Position integral (P.I.): Let α = βmω²/2:

∫−∞∞ e−βmω²x²/2 dx = √(2π/(βmω²)) = √(2πkBT/(mω²))

Combining:

Z1 = (1/h) · √(2πmkBT) · √(2πkBT/(mω²)) = (1/h) · 2πkBT/ω = kBT/(ħω)

For the 3D oscillator, each dimension contributes independently:

Z13D = (kBT/ħω)3
Z1(1D) = kBT/(ħω)     Z1(3D) = (kBT/ħω)3

Total Partition Function

ZN = (Z1)N = (kBT/ħω)N   [1D]   or   (kBT/ħω)3N   [3D] Distinguishable particles: no 1/N! factor

Helmholtz Free Energy

F = −kBT ln ZN = −NkBT ln(kBT/ħω)   [1D]

Entropy

S = −(∂F/∂T)V = NkB[1 + ln(kBT/ħω)]   [1D]
S = 3NkB[1 + ln(kBT/ħω)]   [3D]

Average Energy and Heat Capacity

⟨E⟩ = U = NkBT   [1D, from equipartition: 2 quadratic DoF × ½kBT]
U = 3NkBT   [3D]
CV = NkB   [1D]    CV = 3NkB   [3D — Dulong–Petit law] Classical Dulong–Petit: CV = 3NkB per mole = 3R
The Dulong–Petit Law
For a 3D solid of N atoms treated as distinguishable harmonic oscillators, CV = 3NkB = 3R per mole. This was observed experimentally long before statistical mechanics existed. It breaks down at low temperatures — the quantum Einstein and Debye models fix this, giving CV → 0 as T → 0 in agreement with the third law of thermodynamics.

Pressure

P = −(∂F/∂V)T = 0

Again zero, for the same reason as the 2D case: the harmonic oscillator Hamiltonian is volume-independent.

Conceptual Questions

Why does the Dulong–Petit law fail at low temperatures?
The classical partition function treats energy as continuous, which is valid when kBT ≫ ħω. At low T, quantum mechanics forces the oscillator into discrete energy levels nħω. When kBT ≪ ħω, thermal fluctuations cannot excite the oscillator from its ground state, so it contributes nothing to the heat capacity. The quantum correction (Einstein model) gives CV ∝ (ħω/kBT)² e−ħω/kBT → 0 as T→0.
Derive the average energy using U = −∂(ln Z)/∂β directly.
For 1D: ln ZN = N ln(kBT/ħω) = N ln(1/(βħω)) = −N ln(βħω). Therefore U = −∂(ln ZN)/∂β = −∂/∂β(−N ln βħω) = N · ∂(ln β)/∂β = N/β = NkBT. ✓

Classical Ideal Gas in the Grand Canonical (Macro-canonical) Ensemble

Grand Canonical Ensemble  ·  Pathria Ch. 4 · Reif Ch. 9

The Grand Canonical Partition Function

In the grand canonical ensemble, both energy and particle number fluctuate. The system is in contact with a heat bath (temperature T) and a particle reservoir (chemical potential μ). The grand partition function is:

Ξ = ΣN=0∞ Σstates e−β(Ei − μN) = ΣN=0∞ eβμN ZN Grand partition function (grand canonical sum)

Here ZN is the canonical partition function for exactly N particles.

Hamiltonian

H = p²/(2m)   (single particle, 3D ideal gas)

Canonical Partition Function for N Indistinguishable Particles

ZN = (1/N!) (Z1)N

The 1/N! accounts for indistinguishability. The single-particle partition function is:

Z1 = (1/h³) ∫ d³q d³p e−βp²/2m

The position integral gives the total volume: ∫d³q = V. The momentum integral:

∫ d³p e−βp²/2m = (∫−∞∞ dpx e−βpx²/2m)3 = (2πmkBT)3/2
▶ Derivation: Single-particle partition function and thermal de Broglie wavelength
Z1 = V/h³ · (2πmkBT)3/2

Define the thermal de Broglie wavelength:

λ = h/√(2πmkBT)

Then: λ³ = h³/(2πmkBT)3/2, so:

Z1 = V/λ³

Physical interpretation: λ is the quantum length scale below which quantum effects become important. When the inter-particle spacing (V/N)1/3 ≫ λ, classical statistics is valid. When (V/N)1/3 ~ λ, quantum degeneracy effects (Fermi-Dirac or Bose-Einstein) become crucial.

Z1 = V/λ³   where   λ = h/√(2πmkBT) Thermal de Broglie wavelength
ZN = (1/N!)(V/λ³)N

Grand Partition Function

Ξ = ΣN=0∞ eβμN · (1/N!)(V/λ³)N = ΣN=0∞ (1/N!)(Veβμ/λ³)N

This is exactly the Taylor series for the exponential function:

Ξ = exp(V eβμ/λ³) Grand partition function for the classical ideal gas

Grand Potential

Ω(T,V,μ) = −kBT ln Ξ = −kBT · (V/λ³) eμ/kBT

Thermodynamic Properties from Grand Potential

1. Average number of particles ⟨N⟩

⟨N⟩ = (1/β)(∂ ln Ξ/∂μ)T,V = kBT · (∂ ln Ξ/∂μ) = (V/λ³) eβμ Average particle number in the grand canonical ensemble

Rearranging: eβμ = ⟨N⟩λ³/V, so μ = kBT ln(⟨N⟩λ³/V).

2. Internal energy ⟨E⟩

▶ Derivation of internal energy

ln Ξ = (V/λ³)eβμ. We need ∂(ln Ξ)/∂β at fixed V, μ.

Write λ = h/√(2πmkBT) = h · (β/2πm)1/2, so λ³ = h³(β/2πm)3/2.

Therefore V/λ³ = V(2πm)3/2/(h³β3/2).

ln Ξ = V(2πm/h²)3/2 β−3/2 eβμ
∂(ln Ξ)/∂β = V(2πm/h²)3/2 eβμ[−(3/2)β−5/2 + μβ−3/2]
= (V/λ³) eβμ[μ − (3/2)/β] = ⟨N⟩[μ − (3/2)kBT]
⟨E⟩ = −∂(ln Ξ)/∂β + μ⟨N⟩ = ⟨N⟩[(3/2)kBT] = (3/2)⟨N⟩kBT
⟨E⟩ = (3/2)⟨N⟩kBT Internal energy — classical ideal gas (3 translational DoF × ½kBT each)

3. Entropy — the Sackur-Tetrode equation

S = ⟨N⟩kB[5/2 − ln(⟨N⟩λ³/V)] Sackur–Tetrode equation for the ideal gas
Sackur–Tetrode: Physical Meaning
The entropy depends on V/⟨N⟩ (volume per particle) and λ³ (quantum volume per particle). The ratio ⟨N⟩λ³/V = nλ³ is the "quantum concentration" — a measure of how much phase space each particle needs. When nλ³ ≪ 1 (dilute gas, high T), S is large and positive. When nλ³ → 1, quantum effects take over. This equation automatically satisfies extensivity (S ∝ N when V ∝ N) because of the 1/N! factor.

4. Helmholtz free energy

F = ⟨E⟩ − TS = ⟨N⟩kBT[ln(⟨N⟩λ³/V) − 1]

5. Gibbs free energy and chemical potential

G = F + PV = ⟨N⟩kBT ln(⟨N⟩λ³/V) = ⟨N⟩μ

So G = Nμ as expected from the Euler relation. This confirms our expression for μ.

6. Pressure — Ideal Gas Law

P = −(∂Ω/∂V)T,μ = kBT eβμ/λ³ = ⟨N⟩kBT/V
∴ PV = ⟨N⟩kBT     (Ideal Gas Law — derived from first principles!) The ideal gas law emerges naturally from the grand canonical treatment

7. Heat capacities

CV = (∂⟨E⟩/∂T)N,V = (3/2)⟨N⟩kB
CP = CV + NkB = (5/2)⟨N⟩kB
γ = CP/CV = 5/3    (monatomic ideal gas)

8. Enthalpy

H = ⟨E⟩ + PV = (3/2)⟨N⟩kBT + ⟨N⟩kBT = (5/2)⟨N⟩kBT

Conceptual Questions

What is the physical significance of the thermal de Broglie wavelength?
λ = h/√(2πmkBT) represents the quantum mechanical "fuzziness" of a particle at temperature T — roughly the spread of its wavepacket due to thermal motion. When particles are separated by distances ≫ λ, their wavefunctions don't overlap and classical (Maxwell-Boltzmann) statistics applies. When the mean inter-particle distance ~ λ, wave-functions overlap significantly and quantum statistics (Fermi-Dirac or Bose-Einstein) must be used. At room temperature, λ ~ 0.1 Å for electrons in metals, meaning electrons are always in the quantum degenerate regime.
Why is the 1/N! factor necessary for indistinguishable particles?
Without the 1/N!, swapping two particles in the same energy state would count as a new microstate, which is incorrect for identical particles. The overcounting by N! (the number of permutations of N particles) leads to the Gibbs paradox: without 1/N!, the entropy of mixing two ideal gases of the same species would be non-zero, violating the fact that mixing identical gases is not a thermodynamically irreversible process. The 1/N! makes entropy extensive (S ∝ N at fixed T and n = N/V).
Why does G = Nμ for the ideal gas?
This is actually a fundamental thermodynamic identity (Euler's relation) for any system with one component: G = Nμ by definition. The chemical potential μ is the Gibbs free energy per particle. This can be derived from the extensivity of thermodynamic functions: if we scale the system by a factor λ (scaling N, V, E all by λ), then G scales as λG = G(λN, P, T), and differentiating with respect to λ at λ=1 gives the Euler relation.

Classical Ideal Gas in the Canonical Ensemble

Canonical Ensemble · Sackur–Tetrode via Stirling  ·  Reif Ch. 7 · Pathria Ch. 3

Setup

Same system — N identical, non-interacting point particles in volume V, with Hamiltonian H = Σi pi²/2m — but now in the canonical ensemble (fixed T, V, N).

Z(T,V,N) = (1/N!) (1/h3N) ∫∏i=1N d³ri d³pi e−βΣpi²/2m
▶ Full derivation of the canonical partition function and Helmholtz free energy

Step 1: Position integral for each particle gives V (phase space volume), and for N particles: ∫∏d³ri = VN.

Step 2: Momentum integral for each particle in 3D:

∫d³p e−βp²/2m = (2πmkBT)3/2

For N particles: ∏i=1N(2πmkBT)3/2 = (2πmkBT)3N/2.

Step 3: Total partition function:

Z = (1/N!) (V/h³)^N (2πmkBT)3N/2 / h0
Z = (1/N!) (V(2πmkBT)3/2/h³)N = (1/N!)(V/λ³)N

Step 4: ln Z using Stirling's approximation (ln N! ≈ N ln N − N):

ln Z = −ln N! + N ln(V/λ³) ≈ −(N ln N − N) + N ln(V/λ³) = N ln(V/Nλ³) + N

Step 5: Helmholtz free energy:

F = −kBT ln Z = −NkBT[ln(V/Nλ³) + 1]
F = −NkBT [ln(V/(Nλ³)) + 1] Helmholtz free energy — classical ideal gas (canonical)

Internal Energy

U = −∂(ln Z)/∂β = (3/2)NkBT Derived from ln Z = N ln(V/λ³) − ln N!, noting λ ∝ β1/2

Entropy — Sackur-Tetrode Equation

S = −(∂F/∂T)N,V = NkB[ln(V/Nλ³) + 5/2] Sackur–Tetrode equation (same as grand canonical result — ensembles agree!)

Pressure and Ideal Gas Law

P = −(∂F/∂V)T,N = NkBT/V    ⟹    PV = NkBT

Chemical Potential

μ = (∂F/∂N)T,V = −kBT[ln(V/Nλ³) + 1] + NkBT · 1/N = kBT ln(Nλ³/V)
Ensemble Equivalence
The canonical and grand canonical ensembles give exactly the same thermodynamic properties in the thermodynamic limit (N → ∞). This is ensemble equivalence: relative fluctuations in N (grand canonical) vanish as 1/√N, so for N ~ 1023 the ensembles are indistinguishable. The two routes always agree for the ideal gas.

Conceptual Questions

Show that the entropy from the canonical ensemble is extensive.
S = NkB[ln(V/Nλ³) + 5/2]. If we scale N → 2N and V → 2V (keeping density n = N/V fixed): S → 2NkB[ln(2V/2Nλ³) + 5/2] = 2NkB[ln(V/Nλ³) + 5/2] = 2S. ✓ The entropy is extensive. Without the 1/N! factor, we would get ln(V/λ³) instead of ln(V/Nλ³), which would change by ln 2 per particle upon doubling — this is the Gibbs paradox.
What happens to the classical ideal gas entropy as T → 0?
As T → 0, λ = h/√(2πmkBT) → ∞, so Nλ³/V → ∞ and ln(V/Nλ³) → −∞. The entropy S → −∞, which violates the third law of thermodynamics (S ≥ 0). This is a failure of classical statistics: at low T, quantum mechanics must be used. Quantum statistics (Fermi-Dirac for fermions, Bose-Einstein for bosons) correctly gives S → 0 as T → 0.

Ultrarelativistic Gas in the Canonical Ensemble

Massless or high-T limit: E = pc  ·  Pathria Ch. 3 High Weightage

What is an Ultrarelativistic Gas?

Physical Regime
In the ultrarelativistic limit, either the particles are massless (photons, neutrinos) or the kinetic energy pc ≫ mc². The full relativistic energy-momentum relation E = √(p²c² + m²c⁴) simplifies to:

E = pc = |p|c    (ultrarelativistic dispersion)

Examples: photon gas (blackbody radiation in the classical limit), ultra-hot plasma, and as an interesting pedagogical limit of the relativistic canonical ensemble.

Partition Function for N Indistinguishable Particles

H = Σi=1N |pi|c    (total Hamiltonian)
Z(T,V,N) = (1/N!h3N) ∫∏i=1N d³qi d³pi e−βΣ|pi|c

The position integral gives V per particle; the partition function factorizes:

Z = (1/N!)(V/h³)N (∫ d³p e−β|p|c)N = (1/N!) Z1N
▶ Derivation: Single-particle momentum integral using spherical coordinates

In spherical coordinates in momentum space: d³p = p² dp sin θ dθ dφ. The angular integral gives 4π:

∫ d³p e−βpc = 4π ∫0∞ p² e−βpc dp

Let u = βpc, so p = u/(βc), dp = du/(βc), p² = u²/(βc)²:

= 4π · (1/(βc)²) · (1/(βc)) ∫0∞ u² e−u du = 4π · (1/(βc)³) · Γ(3)

Now Γ(3) = 2! = 2, therefore:

∫ d³p e−βpc = 8π/(βc)³ = 8πkB³T³/c³

Single-particle partition function:

Z1 = (V/h³) · 8π/(βc)³ = 8πV(kBT)³/(h³c³) = 8πV(kBT/hc)³
Z1 = 8πV(kBT)³/(h³c³)
ZN = (1/N!) [8πV(kBT)³/(h³c³)]N = (VN/N!) [8π(kBT/hc)³]N Partition function — ultrarelativistic gas

Helmholtz Free Energy

Using Stirling: ln N! ≈ N ln N − N:

ln ZN = N ln V − (N ln N − N) + N ln[8π(kBT/hc)³]
F = −kBT ln ZN = −NkBT [1 + ln(8πV(kBT)³/(Nh³c³))] Helmholtz free energy — ultrarelativistic gas

Entropy

S = −(∂F/∂T)N,V = NkB[4 + ln(8πV(kBT)³/(Nh³c³))]

Internal Energy

U = F + TS = 3NkBT Each ultrarelativistic particle contributes 3kBT — compare to 3/2 kBT for non-relativistic!
Non-relativistic vs. Ultrarelativistic Comparison
QuantityNon-relativistic (E = p²/2m)Ultrarelativistic (E = pc)
⟨E⟩ per particle(3/2)kBT3kBT
CV(3/2)NkB3NkB
Equation of statePV = NkBTPV = NkBT
P vs U relationPV = (2/3)UPV = (1/3)U

The ultrarelativistic energy is exactly double — this follows from dimensional analysis: with only one energy scale (kBT) and E ∝ p (not p²), the equipartition theorem must give a different numerical prefactor.

Pressure and Equation of State

P = −(∂F/∂V)T,N = NkBT/V    ⟹    PV = NkBT

The ideal gas law is the same as the non-relativistic case — but note that U = 3NkBT = 3PV, not (3/2)PV. This is the relativistic equation of state for radiation: P = U/(3V).

Conceptual Questions

Why does the ultrarelativistic gas have U = 3NkBT instead of (3/2)NkBT?
The factor comes from the different dispersion relation E ∝ p vs E ∝ p². In the non-relativistic case, the Gaussian integral over e−βp²/2m in d dimensions gives ⟨E⟩ = (d/2)kBT per particle. For the ultrarelativistic case with E = pc, we integrate e−βpc in 3D using spherical coordinates. The average energy is ⟨E⟩ = ⟨pc⟩ = c⟨p⟩. Since ∫p³ e−βpcdp/∫p² e−βpcdp = 3/(βc), we get ⟨E⟩ = 3/β = 3kBT. The rule is: for E ∝ ps in d dimensions, ⟨E⟩ = (d/s)kBT.
How does this relate to photons and the Stefan-Boltzmann law?
Photons are massless bosons with E = pc. The classical limit of the photon gas (Rayleigh-Jeans) treats them classically. However, the full quantum treatment (Planck distribution) gives the Stefan-Boltzmann law for radiation energy density u ∝ T⁴. The T³ factor in the ultrarelativistic partition function Z1 ∝ T³V is the classical counterpart — quantum mechanically, ⟨E⟩ ∝ T⁴V for the photon gas. The classical ultrarelativistic result correctly predicts the PV = U/3 equation of state for radiation.

Relativistic Gas in the Canonical Ensemble

Full relativistic dispersion · Modified Bessel functions  ·  Pathria Ch. 3

Energy-Momentum Relation

E = √(p²c² + m²c⁴) = mc² √(1 + (pc/mc²)²) Full relativistic dispersion relation

Partition Function

Z(T,V,N) = (1/N!h3N) ∫∏d³q d³p e−β Σ √(pi²c² + m²c⁴) = (1/N!) (Z1)N

The single-particle partition function Z1 = (V/h³) ∫d³p e−β√(p²c²+m²c⁴). In spherical coordinates:

Z1 = (V/h³) · 4π ∫0∞ p² e−β√(p²c²+m²c⁴) dp
▶ Derivation: Z1 in terms of the modified Bessel function K2

Let x = βpc, so p = x/(βc), dp = dx/(βc), p² = x²/(βc)²:

Z1 = (4πV/h³)(kBT/c)³ ∫0∞ x² e−β mc²√(1+x²/(βmc²)²) dx

Let α = βmc². Then:

Z1 = (4πV/h³)(kBT/c)³ ∫0∞ x² e−√(x²+α²) dx

This integral is a standard form related to the modified Bessel function of the second kind:

∫0∞ e−√(x²+α²) x² dx = α² K2(α)

where Kn(α) = (αn/(2n−1Γ(n+1))) ∫0∞ e−α cosh t sinh2nt dt.

Therefore:

Z1 = (4πV/h³)(kBT/c)³ α² K2(α) = (4πVm²c/(h³β)) K2(βmc²) = (4πVm²c kBT/h³) K2(mc²/kBT)

More compactly, Z1 = (4πVm²c²/(h³β)) K2(βmc²).

Z1 = (4πVm²c²/h³β) K2(βmc²)    where α = βmc²
ZN = (1/N!)(4πVm²c²/h³β)N K2N(βmc²) Partition function — relativistic gas (Jüttner distribution)

Limiting Cases

a) Non-relativistic limit (mc² ≫ kBT, i.e., α ≫ 1):

For large α, the asymptotic form of the Bessel function is K2(α) ≈ √(π/2α) e−α.

Z1 ≈ (4πV/h³)(m/β)3/2/2 × e−βmc² · √(2π) = (V/λ³) e−βmc²

The e−βmc² factor is the rest mass contribution to the energy. If we measure energies relative to mc², this recovers the non-relativistic ideal gas result. ✓

b) Ultrarelativistic limit (mc² ≪ kBT, i.e., α → 0):

For small α, K2(α) ≈ 2/α².

Z1 ≈ (4πV/h³)(kBT/c)³ · 2 = 8πV(kBT)³/(h³c³)

This recovers the ultrarelativistic result from the previous lecture. ✓

Modified Bessel Function Kn
Kn(α) = (αn/(2n−1Γ(n+1))) ∫0∞ e−α cosh t sinh2nt dt. These functions appear naturally in relativistic statistical mechanics whenever the energy-momentum relation mixes linear (relativistic) and quadratic (non-relativistic) terms. Key limits: Kn(α) → Γ(n)·2n−1/αn as α → 0, and Kn(α) → √(π/2α) e−α as α → ∞.

Conceptual Questions

Why does the Bessel function K2 appear in the relativistic partition function?
The Bessel function arises from the structure of the relativistic integral ∫p² e−β√(p²c²+m²c⁴)dp. Unlike the Gaussian integral (non-relativistic) or the simple exponential integral (ultrarelativistic), the mixed form √(p²c²+m²c⁴) cannot be evaluated in closed form using elementary functions. The substitution p = mc sinh t transforms it into an integral representation of K2. This is why relativistic statistical mechanics necessarily involves special functions.

Law of Atmospheres in the Canonical Ensemble

Barometric formula · Canonical ensemble in external field  ·  Reif Ch. 7

Physical Setup

Consider an ideal gas of N particles, each with mass m, in a uniform gravitational field g = −gẑ. The gravitational potential energy per particle at height z is U(z) = mgz. The total Hamiltonian is:

H = p²/(2m) + mgz Hamiltonian with gravitational potential energy

Single-Particle Canonical Partition Function

Z1 = (1/h³) ∫ e−βH d³r d³p = (1/h³) [∫ e−βp²/2m d³p] [∫ e−βmgz d³r]

The momentum integral (M.I.) is the standard Gaussian:

∫ e−βp²/2m d³p = (2πmkBT)3/2

The position integral (P.I.) separates. The x and y integrals give the cross-sectional area A (since the gas fills a column of cross-section A from z = 0 to ∞):

P.I. = A ∫0∞ e−βmgz dz = A · (1/(βmg)) = AkBT/(mg)
Z1 = (2πmkBT)3/2 / h³ · AkBT/(mg) Single-particle partition function — gas in gravitational field

Density Distribution n(z)

The probability density for a single particle to be at height z is proportional to the Boltzmann factor:

P(z) ∝ e−βmgz

The number density (particles per unit volume) at height z is:

n(z) = n₀ e−mgz/kBT = n₀ e−βmgz Barometric density distribution

where n₀ is the density at z = 0. Normalising: N = ∫0∞ n(z) A dz = n₀ A/(βmg), giving n₀ = Nβmg/A = Nmg/(AkBT).

Pressure Distribution — Barometric Formula

For an ideal gas, pressure P = nkBT, so:

P(z) = n(z) kBT = n₀ kBT e−mgz/kBT = P₀ e−mgz/kBT Barometric formula — pressure decreases exponentially with altitude

The characteristic height (scale height) over which P drops by a factor e is:

H = kBT/(mg)    [scale height]

For Earth's atmosphere with m ≈ 4.8×10−26 kg (average air molecule), T = 288 K: H ≈ 8.5 km.

Alternative Derivation: Hydrostatic Equilibrium

We can also derive the barometric formula from hydrostatic equilibrium (force balance on a slab of gas at height z with thickness dz):

dP/dz = −n(z)mg = −ρg Hydrostatic equilibrium condition

Since P(z) = n(z)kBT, substituting:

dP/dz = −P(z) mg/(kBT)    ⟹    P(z) = P₀ e−mgz/kBT ✓

This elementary approach agrees with the canonical ensemble result, confirming ensemble correctness.

Conceptual Questions

Why does the density decrease exponentially with height (rather than, say, linearly)?
The exponential profile is a direct consequence of the Boltzmann distribution. The probability of a particle being at height z is proportional to e−βmgz — the probability decreases exponentially with potential energy mgz. More intuitively: at every height, the fraction of molecules with enough kinetic energy to climb an additional dz is e−mgdz/kBT, so the density has this multiplicative structure at every step, leading to exponential decay. This is the same as the Maxwell-Boltzmann factor applied to gravitational potential energy.
The barometric formula assumes constant temperature. How does the real atmosphere differ?
The real atmosphere is not isothermal: temperature decreases with altitude in the troposphere (lapse rate ~ 6.5 K/km) due to adiabatic cooling of rising air parcels. In the stratosphere, temperature actually increases with altitude due to ozone absorption. For the isothermal approximation to be valid, we need the temperature to be uniform — this is better in the upper stratosphere and above. The real pressure profile is a modified barometric formula using the temperature profile T(z), often approximated as P(z) = P₀(1 − Lz/T₀)gM/RL where L is the lapse rate.

Micro-canonical Ensemble — Phase Space and Entropy

Relating micro and macro: Ω, S, and the equation of state  ·  Reif Ch. 2–3 · Pathria Ch. 1–2

The Micro-canonical Ensemble

Fundamental Postulate
In the micro-canonical ensemble, the system is isolated: E, V, and N are all fixed (to within a small width δE). Every microstate with energy in [E, E+δE] is equally probable. The density of states (number of accessible microstates) is:

Ω(E, V, N) = (number of microstates with energy in [E, E+δE])

Boltzmann's entropy: S = kB ln Ω(E, V, N)

Micro-canonical Ensemble for 1D Classical Harmonic Oscillators

For N distinguishable 1D classical harmonic oscillators (lattice, e.g., Einstein model), with H = Σ[pi²/2m + ½mω²xi²], the phase space volume for energy up to E is the volume of a 2N-dimensional ellipsoid:

Σ(E) = (1/hN) × Volume of 2N-dim ellipsoid defined by Σ[pi²/2m + ½mω²xi²] ≤ E

Shape of the energy surface

Each oscillator contributes a term of the form p²/(2m) + ½mω²x² ≤ E. The phase-space "ball" has semi-axes a = √(2mE) in momentum directions and b = √(2E/mω²) in position directions.

Volume of a 2N-dimensional ellipsoid with semi-axes a in N momentum directions and b in N position directions:

V2N = πN/(N!) × aN × bN = πN/(N!) × (2mE)N/2 × (2E/mω²)N/2
Σ(E) = V2N/hN = (πN/N!hN) × 2NEN/ωN = (1/N!)(E/ħω)N
▶ Derivation: Density of states Ω(E) and entropy S(E,V,N)

The density of states (number of microstates per unit energy) is:

g(E) = ∂Σ/∂E = (1/N!) · N(E/ħω)N−1 · 1/(ħω) = (1/(N-1)!)(E/ħω)N−1/(ħω)

For large N: Ω(E) ≈ g(E)·δE. Using Stirling:

ln Ω = ln[(1/N!)(E/ħω)N] = N ln(E/ħω) − ln N! ≈ N ln(E/ħω) − N ln N + N
S = kB ln Ω = NkB[1 + ln(E/Nħω)]

Temperature from entropy:

1/T = (∂S/∂E)N,V = NkB/E    ⟹    E = NkBT ✓

This is consistent with the canonical result U = NkBT for 1D oscillators. Ensembles agree!

S(E,V,N) = NkB[1 + ln(E/Nħω)] Entropy of N distinguishable 1D classical harmonic oscillators (micro-canonical)

Relation Between Ensembles

Micro ↔ Canonical ↔ Grand Canonical

Micro-canonical: Ω(E,V,N)  →  S = kBln Ω  →  T = 1/(∂S/∂E)

Canonical: Z(T,V,N) = ∫Ω(E)e−βEdE  →  F = −kBT ln Z

Grand Canonical: Ξ(T,V,μ) = ΣNeβμNZN  →  ΩGC = −kBT ln Ξ

All three are equivalent in the thermodynamic limit (N→∞). The differences only matter for small systems.

Micro-canonical for the Ultrarelativistic Gas

For N ultrarelativistic particles in 3D with E = Σ|pi|c, the number of microstates involves the volume of a 3N-dimensional sphere in momentum space subject to Σ|pi| = E/c.

Ω(E) ∝ VN E3N Density of states scales as E3N for the ultrarelativistic gas
S = kBln Ω = NkBln V + 3NkBln E + const.
1/T = ∂S/∂E = 3NkB/E    ⟹    E = 3NkBT ✓

Consistent with the canonical result. The micro-canonical and canonical ensembles agree.

Conceptual Questions

Why do all three ensembles give the same thermodynamic results for large N?
For a macroscopic system (N ~ 1023), the probability distribution of energy E (in the canonical ensemble) is sharply peaked around ⟨E⟩ with a width of order √N. The relative width σE/⟨E⟩ ~ 1/√N → 0 as N→∞. This means the canonical ensemble effectively enforces E = ⟨E⟩ exactly in the thermodynamic limit, making it equivalent to the micro-canonical ensemble where E is truly fixed. The same argument applies to fluctuations in N in the grand canonical ensemble. Ensemble equivalence is a statement about the dominance of the mean over fluctuations for large systems.
What is Boltzmann's tombstone equation S = k ln W and what does W mean?
The equation S = kB ln W (where W = Ω is the number of accessible microstates) is inscribed on Boltzmann's tombstone. It is the fundamental bridge between the microscopic and macroscopic descriptions of matter. W counts the number of distinct microscopic arrangements of all the atoms/molecules that give the same macroscopic state (same E, V, N). For a gas with N ~ 1023, W is an astronomically large number (order 1010²³), and the log brings it back to a manageable O(N) quantity.

Important Questions — High Weightage Topics

Exam preparation · Detailed model answers  ·  Exam Focus
Strategy Note
The highest-weightage topics in this course are: (1) Partition function derivations for classical oscillators and ideal gases, (2) Deriving thermodynamic potentials from Z, (3) The grand canonical partition function and grand potential, (4) Equation of state derivations, and (5) Comparing classical, non-relativistic, and ultrarelativistic cases.
Q1. Derive all thermodynamic properties of N distinguishable 2D classical harmonic oscillators from first principles. [Long Answer]
System: H = px²/2m + py²/2m + ½mω²(x² + y²).

Single-particle partition function:
Z1 = (1/h²)∫e−βHdx dy dpxdpy. Each of the 4 Gaussian integrals contributes: ∫e−βp²/2mdp = √(2πm/β) and ∫e−βmω²x²/2dx = √(2π/βmω²). Therefore:
Z1 = (1/h²) · (2πm/β) · (2π/βmω²) = 4π²/(h²β²ω²) = (kBT/ħω)².

Total partition function (distinguishable):
ZN = Z1N = (kBT/ħω)2N.

Helmholtz free energy:
F = −kBT ln ZN = −2NkBT ln(kBT/ħω).

Internal energy (equipartition):
U = −∂(ln ZN)/∂β = 2N/β = 2NkBT. (4 quadratic DoF × ½kBT each).

Entropy:
S = −(∂F/∂T) = 2NkB[1 + ln(kBT/ħω)].

Heat capacity: CV = 2NkB.

Pressure: P = −(∂F/∂V) = 0 (H is volume-independent).

Chemical potential: μ = (∂F/∂N) = −2kBT ln(kBT/ħω).

Average energy per oscillator: ⟨E⟩ = U/N = 2kBT. By equipartition, with 4 quadratic terms each contributing ½kBT.
Q2. Starting from the grand partition function, derive the ideal gas law PV = NkBT and the Sackur-Tetrode entropy formula. [Long Answer]
Grand partition function:
For the classical monatomic ideal gas with ZN = (1/N!)(V/λ³)N where λ = h/√(2πmkBT):
Ξ = ΣN eβμN(V/λ³)N/N! = exp(Veβμ/λ³).

Grand potential:
Ω = −kBT ln Ξ = −kBT · (V/λ³)eβμ.

Average particle number:
⟨N⟩ = −(∂Ω/∂μ)T,V = (V/λ³)eβμ → eβμ = ⟨N⟩λ³/V.

Pressure:
P = −(∂Ω/∂V)T,μ = kBT·eβμ/λ³ = ⟨N⟩kBT/V → PV = NkBT ✓

Sackur-Tetrode entropy:
Ω = −kBT · Veβμ/λ³ = −⟨N⟩kBT (grand potential).
From thermodynamics, Ω = F − μN = F − ⟨N⟩μ. Using F = −⟨N⟩kBT[ln(V/⟨N⟩λ³)+1]:
S = −(∂F/∂T)N,V = ⟨N⟩kB[ln(V/⟨N⟩λ³) + 5/2].

The 5/2 comes from: ln(V/⟨N⟩λ³) from the particle number term, +1 from −N·∂(−kBT)/∂T = NkB, and +3/2 from −N·∂(−kBT·ln λ⁻³)/∂T = 3NkB/2 (since λ ∝ T−1/2).
Q3. Compare the thermodynamics of the non-relativistic and ultrarelativistic ideal gases. Derive the equation of state for both and explain the difference in U. [Medium Answer]
Non-relativistic (E = p²/2m):
Z1 = V(2πmkBT)3/2/h³ = V/λ³.
U = (3/2)NkBT, PV = NkBT, so PV = (2/3)U.

Ultrarelativistic (E = pc):
Z1 = 8πV(kBT)³/h³c³.
U = 3NkBT, PV = NkBT, so PV = (1/3)U.

Key difference in U: Non-relativistic: 3 translational quadratic degrees of freedom → (3/2)kBT per particle. Ultrarelativistic: the dispersion E = pc is linear in p, not quadratic. The average E = c⟨|p|⟩ = 3kBT (from computing ⟨p⟩ over the distribution ∝ p² e−βpc). The general rule: E ∝ ps in d dimensions → ⟨E⟩ = (d/s)kBT. NR: s=2, d=3 → (3/2)kBT. UR: s=1, d=3 → 3kBT.

The P–U relation: This is fundamental — PV = (2/3)U for NR and PV = (1/3)U for UR. For stars: the radiation pressure (UR photons) PV = U/3 limits stellar mass (Eddington limit), while gas pressure (NR) PV = 2U/3 dominates in cooler stars.
Q4. What is the significance of the barometric formula? Derive it using (a) canonical ensemble and (b) hydrostatic equilibrium. [Medium Answer]
Significance: The barometric formula P(z) = P₀ e−mgz/kBT describes how atmospheric pressure decreases with altitude. It is a direct manifestation of the Boltzmann distribution in an external field and shows how statistical mechanics predicts macroscopic observables from first principles.

(a) Canonical ensemble:
Single-particle H = p²/2m + mgz. Z1 separates into momentum and position integrals. Position integral: P.I. = A∫0∞e−βmgzdz = A/(βmg). The probability density at height z is proportional to e−βmgz, so n(z) = n₀ e−βmgz and P(z) = n(z)kBT = P₀ e−mgz/kBT.

(b) Hydrostatic equilibrium:
Force balance on a slab at height z: dP = −ρg dz = −nmg dz. With P = nkBT: dP/dz = −Pmg/(kBT). This ODE has solution P = P₀ exp(−mgz/kBT). Both approaches agree ✓.

Scale height: H = kBT/(mg). For Earth's atmosphere, H ≈ 8.5 km. This explains why most of the atmosphere is confined to a thin shell.
Q5. State and prove the equipartition theorem for a classical system. What are its limitations? [Short-Medium Answer]
Statement: For a classical system in thermal equilibrium at temperature T, each quadratic term in the Hamiltonian contributes ½kBT to the average energy.

Proof: Consider a term H₀ = aq² (where q is any coordinate, a is a constant). In the canonical ensemble: ⟨aq²⟩ = ∫aq² e−βaq² dq / ∫e−βaq² dq = −∂/∂β [ln∫e−βaq²dq] = −∂/∂β [½ln(π/aβ)] = 1/(2β) = kBT/2. ✓

Limitations: (1) Quantum mechanics: When kBT ≪ ħω, discrete energy levels matter and the classical result fails (Einstein model correction). (2) Anharmonic potentials: Non-quadratic terms don't obey equipartition. (3) Relativistic systems: The ultrarelativistic E = pc is not quadratic; the "relativistic equipartition" gives ⟨E⟩ = 3kBT per particle, not (3/2)kBT. (4) Quantum fields: Each mode of a quantum field cannot be treated classically at low T (ultraviolet catastrophe in classical radiation theory, resolved by Planck).
Q6. Explain what the chemical potential μ represents physically. Why is μ negative for an ideal gas in the classical limit? [Conceptual]
Physical meaning of μ: The chemical potential μ = (∂F/∂N)T,V = (∂G/∂N)T,P is the change in Helmholtz (or Gibbs) free energy when one particle is added to the system at constant T and V (or T and P). It governs particle flow: particles flow from high μ to low μ, just as heat flows from high T to low T and pressure drives flow from high P to low P. In equilibrium, μ is uniform throughout the system.

Why μ < 0 for classical ideal gas:
μ = kBT ln(Nλ³/V). In the classical regime, nλ³ = Nλ³/V ≪ 1 (dilute gas, high T), so ln(nλ³) < 0, making μ negative. Physically: adding one more particle to a dilute, high-T gas increases entropy (it has many phase-space states available) and this entropy gain lowers the free energy F = U − TS. As T → 0 or n → ∞, μ → 0 from below, and then quantum statistics (Fermi-Dirac or Bose-Einstein) takes over.
Q7. For N distinguishable classical harmonic oscillators in 3D (canonical ensemble), write a mini-derivation roadmap and state the key results. [Short Answer]
Hamiltonian: Htotal = Σi=1N[pi²/2m + ½mω²xi²] (each oscillator has 1 spatial dimension; for 3D oscillator, replace N → 3N).

Z1: (1/h)∫e−βp²/2mdp · ∫e−βmω²x²/2dx = (1/h)·√(2πm/β)·√(2π/βmω²) = kBT/(ħω).

ZN: (kBT/ħω)N [or (kBT/ħω)3N for 3D oscillators].

Key results:
F = −NkBT ln(kBT/ħω)
U = NkBT → CV = NkB [1D] or U = 3NkBT → CV = 3NkB = 3R/mol [3D, Dulong-Petit]
S = NkB[1 + ln(kBT/ħω)]
P = 0 (volume-independent Hamiltonian)
Q8. Using the micro-canonical ensemble, derive the entropy of N distinguishable 1D harmonic oscillators and show it is consistent with the canonical result. [Long Answer]
Phase space volume Σ(E):
The energy surface {Σ pi²/2m + ½mω²xi² ≤ E} is a 2N-dimensional ellipsoid with semi-axes ai = √(2mE) (momentum) and bi = √(2E/mω²) (position). Volume of the 2N-dimensional ellipsoid = πN/N! · aNbN.

Dividing by hN (phase-space cell):
Σ(E) = πN/(N!hN) · (2mE)N/2 · (2E/mω²)N/2 = πN/(N!hN) · (2E)^N/ωN · (m·1/m)N/2
= (1/N!)(2πE/hω)N/... [simplifying] = (1/N!)(E/ħω)N.

Density of states:
g(E) = dΣ/dE = (1/(N-1)!)(E/ħω)N-1/(ħω) ≈ (1/N!)(E/ħω)N/E for large N.

Entropy using Stirling:
S = kB ln Ω = kB ln[(1/N!)(E/ħω)N]
≈ kB[N ln(E/ħω) − N ln N + N] = NkB[1 + ln(E/Nħω)].

Consistency check:
1/T = (∂S/∂E)N = NkB/E → E = NkBT.
This matches the canonical result U = NkBT ✓. Ensembles are equivalent.
